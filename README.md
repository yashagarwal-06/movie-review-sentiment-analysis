# Movie Review Sentiment Analysis

## Overview
This project performs sentiment analysis on IMDb movie reviews using Orange Data Mining.

The objective is to classify reviews as positive or negative using machine learning models.

## Dataset
- IMDb Movie Reviews Dataset
- 50,000 reviews
- Binary sentiment classification

## Preprocessing
- Stopword Removal
- Punctuation Removal
- Porter Stemming
- Bag of Words Transformation

## Models Used
- Naive Bayes
- Logistic Regression
- Random Forest

## Results

| Model | Accuracy |
|---------|---------|
| Logistic Regression | 85.0% |
| Naive Bayes | 83.1% |
| Random Forest | 74.3% |

## Best Model
Logistic Regression achieved the highest performance.

- Accuracy: 85.0%
- AUC: 0.921
- F1 Score: 0.850
